Project Summary:
In this assignment, we implemented and compared various optimization algorithms to predict customer churn in an e-commerce dataset.

Key Steps & Implementation:

Data Preprocessing & Preparation:

Loaded and explored the customer churn dataset.

Handled missing values, applied feature scaling (StandardScaler), and encoded categorical variables using OneHotEncoder via ColumnTransformer and Pipeline.

Split the dataset into training and testing sets with a stratified approach to maintain class distribution.

Model Training & Optimization:

Implemented multiple optimization frameworks and machine learning models (including Stochastic Gradient Descent (SGD), Gradient Descent variations, and other comparative classifiers).

Tuned hyperparameters to optimize model performance, convergence speed, and predictive accuracy.

Evaluation & Comparison:

Evaluated models using key performance metrics such as Confusion Matrix, Classification Report, ROC curve, and AUC score.

Compared the effectiveness of different optimization techniques in handling the classification task efficiently.
